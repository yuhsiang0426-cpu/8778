## 問題回答

問題一：為什麼 "4" 要先轉成數字，才能用於本題的分攤計算？答：
因為在 Python 中，加上引號的 "4" 屬於字串（str）資料型別，電腦只會將它視為一般文字符號，無法進行數學運算。如果直接將總金額（數字型別 float 或 int）除以字串 "4"，Python 會因為型別不相容而引發 TypeError 錯誤導致程式中斷。因此，必須先使用 int() 函式將 "4" 轉換為整數（int）型別，才能順利進行除法運算並得出每人分攤的費用。問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付金額會變成多少？為什麼和題目規定的結果不一樣？答：計算過程與結果：先扣折價券後的剩餘餐費：$1,200 - 100 = 1,100$ 元。依剩餘餐費計算服務費：$1,100 \times 0.10 = 110$ 元。最終應付金額：$1,100 + 110 = 1,210$ 元（比題目規定的 $1,220$ 元少了 $10$ 元）。
